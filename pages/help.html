Como utilizar o Totaliza?

  • 01 - Para utilizar o Totaliza comece por adicionar o orçamento do qual planeja gastar no campo de orçamento, clicando no lápiz:

    Após clicar aparecerá uma tela pedindo o valor total do orçamento.

  • 02 - O Próximo passo é começar a adicionar os produtos dos quais deseja comprar no mercado utilizando o botão de (o circulo com um sinal de +)

  • 03 - Ao clicar em adicionar produtos o site abrirá uma tela te pedindo 3 informações importantes, sendo elas: Nome do produto, valor unitário e quantidade. Preencha todos os campos para conseguir adicionar o produto com sucesso.

  • 04 - Depois de adicionado os itens na lista, o valor deverá ser calculado de forma automática usando de base o valor e quantidade de cada produto adicionado.

    OBS: Se caso seu gasto for maior que o orçamento a calculadora avisará que seu orçamento estourou
