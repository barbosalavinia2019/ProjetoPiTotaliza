
## 🛒 Totaliza – Calculadora Inteligente de Compras

O Totaliza é uma plataforma desenvolvida para facilitar a organização das compras de supermercado, auxiliando os consumidores no controle dos gastos e no planejamento financeiro. Por meio de uma calculadora inteligente, o usuário pode adicionar produtos, informar seus valores e acompanhar o total da compra. Além disso, o projeto incentiva o consumo consciente e a redução do desperdício de alimentos.

### 🚀 Começando

Estas instruções permitirão que você obtenha uma cópia do projeto em sua máquina local para fins de desenvolvimento, teste e utilização.

### 📋 Pré-requisitos

Para acessar e executar o projeto, você precisará de:

-   Um navegador atualizado (Google Chrome, Microsoft Edge ou Firefox).
    

-   Um editor de código, como Visual Studio Code.
    

-   Git (opcional, para clonar o repositório).
    

### 🔧 Instalação

Siga os passos abaixo para obter o projeto:

1. Clone o repositório:

git clone https://github.com/barbosalavinia2019/ProjetoPiTotaliza.git

2. Acesse a pasta do projeto:

cd  ProjetoPiTotaliza

3. Abra a pasta no Visual Studio Code:

4. Execute o projeto:

Abra o arquivo index.html no navegador ou utilize a extensão Live Server do Visual Studio Code.

Após a execução, você poderá navegar pelas páginas e conhecer os recursos disponíveis no Totaliza.

### ⚙️ Executando os testes

O projeto pode ser testado manualmente por meio da navegação pelas páginas e da utilização das funcionalidades disponíveis.

### 🔩 Análise dos testes de funcionamento

Os testes têm como objetivo verificar se as páginas e funcionalidades estão funcionando corretamente.

Alguns pontos que podem ser verificados:

-   Navegação entre as páginas.
    

-   Funcionamento dos links e botões.
    

-   Adição de produtos na calculadora.
    

-   Cálculo e atualização dos valores da compra.
    

-   Exibição correta dos conteúdos e imagens.
    

### ⌨️ Testes de estilo de codificação

A verificação do código busca garantir a organização e a consistência dos arquivos desenvolvidos.

São observados aspectos como:

-   Organização e identação do HTML.
    

-   Estruturação dos estilos CSS.
    

-   Organização dos scripts JavaScript.
    

-   Utilização adequada de classes e identificadores.
    

-   Responsividade das páginas em diferentes tamanhos de tela.
